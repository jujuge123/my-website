# 奢驰美颜全球运营中心 · LUXE CHI BEAUTY

国际高端美妆品牌独立站。**完整电商功能**：多语言、购物车、下单流程、运营后台。

## 文件结构

```
luxe-beauty/
├── index.html        前台主页
├── admin.html        运营后台
├── styles.css        前台样式（黑金主题）
├── admin.css         后台专属样式
├── app.js            前台交互（购物车、结算、i18n、视频、QR）
├── admin.js          后台逻辑（产品/订单/设置/导入导出）
├── db.js             共享数据层（localStorage）
├── i18n.js           多语言资源（中/英/日）
├── netlify.toml      Netlify 部署配置
└── README.md
```

## 直接运行

双击 `index.html`。后台地址 `admin.html`，**默认密码 `luxe2025`**（请尽快在后台修改）。

## 功能清单

### 前台
- **三语切换** 中文 / English / 日本語（右上角切换按钮）
- **沉浸式 Hero**、品牌故事、视频影像、滚动动画
- **产品橱窗** 分类筛选、详情弹窗、加入购物车
- **购物车抽屉** 增减数量、移除、实时金额、徽章计数
- **结算流程** 配送信息表单、5 种支付方式、订单摘要
- **订单成功页** 自动生成订单号 + 三种联系方式
- **三种联系方式** 微信 / WhatsApp / LINE，QR 码自动生成
- 邮件订阅、完整响应式

### 后台 `admin.html`
- **登录**（首次密码 `luxe2025`）
- **概览** 在售产品、订单总数、待处理、销售额、最新订单、热销榜
- **产品管理** 列表/搜索/添加/编辑/删除、库存管理
- **订单管理** 列表/搜索/状态筛选、详情查看、状态流转（待支付→已支付→已发货→已完成）
- **设置** 修改联系方式（前台同步）、修改密码、导出/导入 JSON 数据、重置产品/清空订单

## 数据存储

所有数据保存在浏览器 `localStorage`：
- `luxe.products.v1` — 产品列表
- `luxe.orders.v1` — 订单列表
- `luxe.settings.v1` — 联系方式、管理密码
- `luxe.cart.v1` — 当前购物车
- `luxe.lang` — 用户语言偏好

> 这是纯前端站点，单浏览器隔离。如需多端同步，可在后台用 **导出/导入** 在不同设备间传输 JSON。

## 自定义指南

### 替换品牌视频
`index.html` 中的 `<source src="...">` 替换为你的 mp4 链接（CDN 或本地路径）。

### 添加 / 编辑产品
登录后台 → 产品管理 → 添加产品。或直接在 `db.js` 中编辑 `DEFAULT_PRODUCTS`。

### 修改联系方式
登录后台 → 设置 → 联系方式。前台联系区与订单成功页会自动同步。

### 主题色
`styles.css` 顶部 `:root` 变量：

```css
--gold: #C9A961;
--cream: #F5EFE6;
--bg: #0B0A09;
```

## 部署到 Netlify

仓库根目录已含 `netlify.toml`，纯静态文件即可部署。

或使用拖拽：访问 [app.netlify.com/drop](https://app.netlify.com/drop)，把 `luxe-beauty` 整个目录拖入即可。

## 浏览器兼容

Chrome / Edge / Safari / Firefox 现代版本均可。
